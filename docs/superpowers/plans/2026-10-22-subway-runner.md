# Subway Runner (3-lane endless runner MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free iPhone/iPad game for one child. A little runner dashes down 3 railway lanes. The player swipes left/right to change lanes, up to jump and down to slide, dodging hurdles, overhead bars and trains while grabbing coins. One hit ends the run. The best score is saved.

**Architecture:** All game rules live in a pure-Swift package `GameCore`: seeded random track generation, deterministic fixed-step runner physics, an autopilot bot and score storage. It has no UIKit or SceneKit, so it's fully tested with `swift test` on the Mac. A thin iOS app (SwiftUI menu/HUD + SceneKit 3D view) renders `GameCore` state and feeds it swipes. The Xcode project is generated from `project.yml` by XcodeGen. Art is SceneKit primitive shapes, and music and sound effects are generated by a script, so there's no licensing risk.

**Tech Stack:** Swift 5 language mode, SwiftUI, SceneKit, AVFoundation, XCTest, XcodeGen 2.46, Xcode 27.1, iOS 17.0+.

## Product Spec

- **Orientation:** portrait only, on iPhone and iPad. Full screen, status bar hidden.
- **Menu:** sky-blue gradient, the title "Subway Runner", "Best: N", a big orange **PLAY** button, the hint "Swipe ← → to change lanes / Swipe ↑ to jump, ↓ to slide" and a mute toggle (top-right).
- **Run:** a 3D camera behind and above the runner. The runner moves forward automatically and speeds up over time. A swipe left/right changes lane (one lane per swipe, clamped at the edges). A swipe up jumps. A swipe down slides, or fast-falls if in the air.
- **Obstacles** (one row every 18 m; each row has 1 or 2 obstacles, so **at least one lane is always free**):
  - **Hurdle** (red/white, low): jump over it.
  - **Bar** (yellow, overhead on posts): slide under it. Jumping still hits it.
  - **Train** (blue, 10 m long, tall): change lanes. Jumping still hits it.
- **Coins:** each row puts 5 coins in a free lane. A coin is worth 10 points.
- **Score:** metres run + 10 × coins. The HUD shows the score and a coin count (top-right) and a "✕" exit button (top-left).
- **Crash:** any contact with an obstacle → a heavy haptic, the crash sound, the music stops and the runner tips over. The "Crash!" panel shows Score, Coins, "New best!" when it's a new best, **Play Again** and **Menu**.
- **Audio:** a looping menu track, a looping run track, and jump, coin and crash sound effects. All are generated by a script. The audio session category is `.ambient`, so the game is silent when the device is on silent. The mute setting is saved.
- **Autoplay (testing and screenshots):** launch arguments:
  - `-autoplay YES` starts a run straight away, steered by `Autopilot`
  - `-idle YES` (with `-autoplay YES`) never steers, so the run crashes into the first obstacle
  - `-seed N` fixes the track; 0 or missing means a random seed
- **Out of scope:** characters to unlock, power-ups, missions, a shop, leaderboards, ads, purchases, accounts, network access and analytics.

## Review Focus

1. **An impossible track would frustrate a child.** The generator always leaves a free lane, and the bot survives 120 s on seeds 1–20. Tests: `testEveryRowLeavesAFreeLaneAndCoinsAreInAFreeLane`, `testAutopilotSurvivesTwoMinutesOnSeeds1to20`. (During pre-verification it survived on all of seeds 1–200.)
2. **Threading:** SceneKit calls `renderer(_:updateAtTime:)` on its render thread. Swipes arrive on the main thread through an `NSLock`-guarded queue. HUD updates and **all `AudioManager` calls** are sent to the main thread (the manager isn't thread-safe).
3. **Frame hitch** (app backgrounded or a slow frame): at most 8 ticks per frame, and the extra time is dropped (`GameController.renderer`).
4. **Silent switch:** the audio session category is `.ambient`.
5. **Restart leaks:** "Play Again" changes `runID`, so SwiftUI builds a brand-new `GameView`, `GameController` and scene. No state carries over.
6. **Edge-of-lane swipes:** swiping left in lane 0 does nothing (`testLaneChangeTakes12TicksAndClampsAtEdges`).

```swift
/// SplitMix64: tiny deterministic random generator. Same seed → same track on every device.
public struct SplitMix64: Equatable {
    public private(set) var state: UInt64
    public init(seed: UInt64) { state = seed }
    public mutating func next() -> UInt64 {
        state &+= 0x9E37_79B9_7F4A_7C15
        var z = state
        z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
        z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
        return z ^ (z >> 31)
    }
    /// Uniform-ish integer in 0..<n (n > 0).
    public mutating func int(_ n: Int) -> Int { Int(next() % UInt64(n)) }
}
```

```swift
public enum ObstacleKind: String, CaseIterable, Equatable {
    case hurdle   // low: jump over
    case bar      // overhead: slide under
    case train    // tall and long: change lane
}

public struct Obstacle: Equatable {
    public let id: Int
    public let kind: ObstacleKind
    public let lane: Int        // 0 = left, 1 = middle, 2 = right
    public let z: Double        // near edge; the far edge is z + length
    public var length: Double { kind == .train ? Track.trainLength : Track.thinLength }
    public init(id: Int, kind: ObstacleKind, lane: Int, z: Double) { self.id = id; self.kind = kind; self.lane = lane; self.z = z }
}

public struct Coin: Equatable {
    public let id: Int
    public let lane: Int
    public let z: Double
    public init(id: Int, lane: Int, z: Double) { self.id = id; self.lane = lane; self.z = z }
}

public struct Track {
    public static let laneWidth = 2.5
    public static let firstRowZ = 40.0
    public static let rowGap = 18.0
    public static let trainLength = 10.0
    public static let thinLength = 0.5
    public static let coinsPerRow = 5
    public static let coinSpacing = 2.0
    public static let coinY = 0.9

    public private(set) var obstacles: [Obstacle] = []
    public private(set) var coins: [Coin] = []
    public private(set) var rowsGenerated = 0
    private var rng: SplitMix64
    private var nextID = 0

    public init(seed: UInt64) { rng = SplitMix64(seed: seed) }

    /// Hand-made track for tests. Don't call generate(upTo:) on it.
    public init(fixed obstacles: [Obstacle], coins: [Coin] = []) {
        rng = SplitMix64(seed: 0)
        self.obstacles = obstacles
        self.coins = coins
    }

    public static func laneX(_ lane: Int) -> Double { Double(lane - 1) * laneWidth }
    public static func rowZ(_ row: Int) -> Double { firstRowZ + Double(row) * rowGap }

    /// Adds rows until the next row would start beyond `z`.
    public mutating func generate(upTo z: Double) {
        while Track.rowZ(rowsGenerated) <= z { addRow(rowsGenerated); rowsGenerated += 1 }
    }

    /// Forgets things the runner has fully passed.
    public mutating func dropBehind(_ z: Double) {
        obstacles.removeAll { $0.z + $0.length < z - 5 }
        coins.removeAll { $0.z < z - 5 }
    }

    private mutating func addRow(_ row: Int) {
        let z0 = Track.rowZ(row)
        let count = row < 3 ? 1 : 1 + rng.int(2)          // 1 or 2 obstacles; one lane always free
        let a = rng.int(3)
        var lanes = [a]
        if count == 2 { lanes.append((a + 1 + rng.int(2)) % 3) }
        for lane in lanes {
            let kind = ObstacleKind.allCases[rng.int(3)]
            obstacles.append(Obstacle(id: nextID, kind: kind, lane: lane, z: z0)); nextID += 1
        }
        let free = (0..<3).filter { !lanes.contains($0) }
        let coinLane = free[rng.int(free.count)]
        for i in 0..<Track.coinsPerRow {
            coins.append(Coin(id: nextID, lane: coinLane, z: z0 + Double(i) * Track.coinSpacing)); nextID += 1
        }
    }
}
```

```swift
public enum Move: Equatable { case none, left, right, up, down }

public struct RunnerState: Equatable {
    public var tick = 0
    public var z = 0.0            // distance run, metres
    public var lane = 1           // target lane
    public var x = 0.0            // sideways position, follows Track.laneX(lane)
    public var y = 0.0            // feet height
    public var vy = 0.0
    public var slideTicks = 0     // > 0 while sliding
    public var coins = 0
    public var collected: Set<Int> = []
    public var crashed = false

    public static let start = RunnerState()
    public var isGrounded: Bool { y == 0 && vy == 0 }
    public var isSliding: Bool { slideTicks > 0 }
    public var height: Double { isSliding ? Runner.slideHeight : Runner.standHeight }
    public var speed: Double { Runner.speed(atTick: tick) }
    public var score: Int { Int(z) + coins * Runner.coinValue }
}

public enum Runner {
    public static let dt = 1.0 / 120.0
    public static let startSpeed = 10.0
    public static let acceleration = 0.1          // m/s gained per second
    public static let maxSpeed = 20.0
    public static let laneSwitchSpeed = 25.0      // sideways m/s → 0.1 s per lane
    public static let jumpVelocity = 9.0
    public static let gravity = 30.0
    public static let fastFallVelocity = -15.0
    public static let slideDuration = 72          // ticks = 0.6 s
    public static let halfWidth = 0.4
    public static let halfDepth = 0.4
    public static let standHeight = 1.8
    public static let slideHeight = 0.9
    public static let coinValue = 10
    public static let coinReach = 0.9

    public static func speed(atTick t: Int) -> Double {
        min(maxSpeed, startSpeed + acceleration * Double(t) * dt)
    }

    /// Box of an obstacle: (x half-width, y bottom, y top).
    static func box(_ kind: ObstacleKind) -> (halfW: Double, y0: Double, y1: Double) {
        switch kind {
        case .hurdle: return (1.0, 0.0, 1.0)
        case .bar: return (1.0, 1.2, 2.2)
        case .train: return (1.1, 0.0, 3.5)
        }
    }

    public static func step(_ s: RunnerState, move: Move, track: Track) -> RunnerState {
        var s = s
        guard !s.crashed else { return s }
        switch move {
        case .left: s.lane = max(0, s.lane - 1)
        case .right: s.lane = min(2, s.lane + 1)
        case .up: if s.isGrounded { s.vy = jumpVelocity; s.slideTicks = 0 }
        case .down:
            if !s.isGrounded { s.vy = min(s.vy, fastFallVelocity) }
            s.slideTicks = slideDuration
        case .none: break
        }
        let maxStep = laneSwitchSpeed * dt
        s.x += max(-maxStep, min(maxStep, Track.laneX(s.lane) - s.x))
        if s.y > 0 || s.vy > 0 {
            s.vy -= gravity * dt
            s.y += s.vy * dt
            if s.y <= 0 { s.y = 0; s.vy = 0 }
        }
        if s.slideTicks > 0 { s.slideTicks -= 1 }
        s.z += speed(atTick: s.tick) * dt
        s.tick += 1

        // overlap(a0, a1, b0, b1) = a0 < b1 && a1 > b0 (strict)
        func overlap(_ a0: Double, _ a1: Double, _ b0: Double, _ b1: Double) -> Bool { a0 < b1 && a1 > b0 }
        let h = s.height
        for o in track.obstacles {
            let b = box(o.kind), ox = Track.laneX(o.lane)
            if overlap(s.x - halfWidth, s.x + halfWidth, ox - b.halfW, ox + b.halfW)
                && overlap(s.y, s.y + h, b.y0, b.y1)
                && overlap(s.z - halfDepth, s.z + halfDepth, o.z, o.z + o.length) {
                s.crashed = true
                return s
            }
        }
        for c in track.coins where !s.collected.contains(c.id) {
            if abs(s.x - Track.laneX(c.lane)) < coinReach && abs(s.z - c.z) < coinReach
                && s.y <= Track.coinY && Track.coinY <= s.y + h {
                s.collected.insert(c.id)
                s.coins += 1
            }
        }
        return s
    }
}

/// One run: the track plus the runner. The app and the tests both drive the game through this.
public struct RunSession {
    public static let generateAhead = 120.0
    public private(set) var state = RunnerState.start
    public private(set) var track: Track

    public init(seed: UInt64) {
        track = Track(seed: seed)
        track.generate(upTo: RunSession.generateAhead)
    }

    public mutating func tick(_ move: Move) {
        state = Runner.step(state, move: move, track: track)
        track.generate(upTo: state.z + RunSession.generateAhead)
        track.dropBehind(state.z)
    }
}
```

```swift
/// A simple bot. Powers autoplay screenshots and proves generated tracks can be survived.
public enum Autopilot {
    public static func move(_ s: RunnerState, track: Track) -> Move {
        let ahead = s.speed * 0.6 + 3
        func trainIn(_ lane: Int, _ z0: Double, _ z1: Double) -> Bool {
            track.obstacles.contains { $0.kind == .train && $0.lane == lane && $0.z < z1 && $0.z + $0.length > z0 }
        }
        if trainIn(s.lane, s.z - 1, s.z + ahead) {
            let order = [s.lane - 1, s.lane + 1, s.lane - 2, s.lane + 2].filter { (0...2).contains($0) }
            for target in order where !trainIn(target, s.z - 1, s.z + ahead) {
                let step = target < s.lane ? -1 : 1
                var lane = s.lane + step, pathClear = true
                while lane != target { if trainIn(lane, s.z - 1.5, s.z + 2.5) { pathClear = false }; lane += step }
                if pathClear { return step < 0 ? .left : .right }
            }
            return .none
        }
        let next = track.obstacles
            .filter { $0.lane == s.lane && $0.kind != .train && $0.z + $0.length > s.z - Runner.halfDepth }
            .min { $0.z < $1.z }
        guard let o = next else { return .none }
        let gap = o.z - (s.z + Runner.halfDepth)
        switch o.kind {
        case .hurdle where s.isGrounded && gap <= s.speed * 0.25: return .up
        case .bar where gap <= s.speed * 0.3 && Double(s.slideTicks) * Runner.dt * s.speed < gap + 1.3: return .down
        default: return .none
        }
    }
}
```

```swift
    /// Never negative, even if storage holds garbage.
```

```swift
    return Double(Int64(bitPattern: lcg) >> 11) / Double(1 << 52)  // roughly -1...1

func freq(_ midi: Double) -> Double { 440 * pow(2, (midi - 69) / 12) }

struct Buf {
    var s: [Double]
    init(seconds: Double) { s = [Double](repeating: 0, count: Int((seconds * rate).rounded())) }
    mutating func add(_ start: Double, _ dur: Double, _ amp: Double, env: Bool = true, _ gen: (Double) -> Double) {
        let i0 = Int((start * rate).rounded())
        let n = Int((dur * rate).rounded())
        for k in 0..<n where i0 + k < s.count {
            let t = Double(k) / rate
            var e = 1.0
            if env {
                e = min(1, t / 0.005)
                e = min(e, max(0, (dur - t) / 0.02))
            }
            s[i0 + k] += amp * e * gen(t)
        }
    }
}

}
```

```swift
import AVFoundation

final class AudioManager {
    static let shared = AudioManager()

    private var music: [String: AVAudioPlayer] = [:]
    private var sfx: [AVAudioPlayer] = []
    private var current: String?

    var isMuted: Bool {
        didSet {
            UserDefaults.standard.set(isMuted, forKey: "muted")
            if isMuted { stopMusic(); sfx.forEach { $0.stop() }; sfx.removeAll() }
        }
    }

    private init() {
        isMuted = UserDefaults.standard.bool(forKey: "muted")
        do {
            let session = AVAudioSession.sharedInstance()
            try session.setCategory(.ambient)
            try session.setActive(true)
        } catch { print("Audio session error: \(error)") }
    }

    private func player(_ name: String) -> AVAudioPlayer? {
        guard let url = Bundle.main.url(forResource: name, withExtension: "wav") else {
            print("Missing audio file: \(name).wav"); return nil
        }
        do { let p = try AVAudioPlayer(contentsOf: url); p.prepareToPlay(); return p }
        catch { print("Audio load error \(name): \(error)"); return nil }
    }

    func playMusic(_ name: String) {
        stopMusic()
        guard !isMuted else { return }
        if music[name] == nil { music[name] = player(name) }
        guard let p = music[name] else { return }
        p.numberOfLoops = -1
        p.currentTime = 0
        p.play()
        current = name
    }

    func stopMusic() {
        if let c = current { music[c]?.stop() }
        current = nil
    }
```

```swift
import SceneKit
import UIKit
import GameCore

/// Owns the 3D scene and the run. SceneKit calls `renderer(_:updateAtTime:)` on its render
/// thread; that is the only place `session` and scene nodes are changed.
/// World → scene mapping: scene position = (x, y, -z). The runner runs toward -z.
final class GameController: NSObject, SCNSceneRendererDelegate {
    let scene = SCNScene()
    let cameraNode = SCNNode()
    private let model: GameModel
    private let autoplay: Bool
    private let idle: Bool
    private let store = ScoreStore()
    private var session: RunSession

    private let lock = NSLock()
    private var pendingMoves: [Move] = []        // guarded by lock (written on main thread)

    private var lastTime: TimeInterval?
    private var accumulator = 0.0
    private var reportedScore = -1
    private var reportedCoins = -1
    private var crashHandled = false
    private var lastJumpTick = -100

    private let runnerNode = SCNNode()
    private var obstacleNodes: [Int: SCNNode] = [:]
    private var coinNodes: [Int: SCNNode] = [:]
    private var segmentNodes: [Int: SCNNode] = [:]

    static let segmentLength = 18.0
    static let viewAhead = 110.0

    init(model: GameModel, autoplay: Bool, idle: Bool, seed: UInt64) {
        self.model = model
        self.autoplay = autoplay
        self.idle = idle
        session = RunSession(seed: seed)
        super.init()
        buildScene()
        AudioManager.shared.playMusic("run")
    }

    // MARK: Input (main thread)

    @objc func swiped(_ g: UISwipeGestureRecognizer) {
        guard !autoplay else { return }
        let move: Move
        switch g.direction {
        case .left: move = .left
        case .right: move = .right
        case .up: move = .up
        default: move = .down
        }
        lock.lock(); pendingMoves.append(move); lock.unlock()
    }

    // MARK: Loop (render thread)

    func renderer(_ renderer: SCNSceneRenderer, updateAtTime time: TimeInterval) {
        guard let last = lastTime else { lastTime = time; syncNodes(); return }
        lastTime = time
        if session.state.crashed { return }
        accumulator += min(time - last, 0.25)
        var ticks = 0
        while accumulator >= Runner.dt && ticks < 8 {
            accumulator -= Runner.dt
            ticks += 1
            session.tick(nextMove())
            if session.state.crashed { break }
        }
        if ticks == 8 { accumulator = 0 }
        syncNodes()
        report()
    }

    private func nextMove() -> Move {
        if autoplay { return idle ? .none : Autopilot.move(session.state, track: session.track) }
        lock.lock(); defer { lock.unlock() }
        return pendingMoves.isEmpty ? .none : pendingMoves.removeFirst()
    }

    private func report() {
        let s = session.state
        // AudioManager is not thread-safe: only call it on the main thread.
        if s.vy > 0 && s.tick - lastJumpTick > 30 {
            lastJumpTick = s.tick
            DispatchQueue.main.async { AudioManager.shared.playSFX("sfx_jump") }
        }
        if s.coins != reportedCoins && reportedCoins >= 0 {
            DispatchQueue.main.async { AudioManager.shared.playSFX("sfx_coin") }
        }
        if s.score != reportedScore || s.coins != reportedCoins {
            reportedScore = s.score; reportedCoins = s.coins
            let score = s.score, coins = s.coins
            DispatchQueue.main.async { self.model.score = score; self.model.coins = coins }
        }
        if s.crashed && !crashHandled {
            crashHandled = true
            let score = s.score
            DispatchQueue.main.async {
                let newBest = self.store.record(score)
                UIImpactFeedbackGenerator(style: .heavy).impactOccurred()
                AudioManager.shared.stopMusic()
                AudioManager.shared.playSFX("sfx_crash")
                self.model.isNewBest = newBest
                self.model.isOver = true
            }
        }
    }

    // MARK: Scene

    private func material(_ hex: UInt32) -> SCNMaterial {
        let m = SCNMaterial()
        m.diffuse.contents = UIColor(red: CGFloat((hex >> 16) & 0xFF) / 255, green: CGFloat((hex >> 8) & 0xFF) / 255,
                                     blue: CGFloat(hex & 0xFF) / 255, alpha: 1)
        m.lightingModel = .lambert
        return m
    }

    private func box(_ w: Double, _ h: Double, _ l: Double, _ hex: UInt32) -> SCNNode {
        let g = SCNBox(width: w, height: h, length: l, chamferRadius: 0)
        g.firstMaterial = material(hex)
        return SCNNode(geometry: g)
    }

    private func buildScene() {
        let sky = UIColor(red: 0.53, green: 0.81, blue: 0.98, alpha: 1)
        scene.background.contents = sky
        scene.fogStartDistance = 60
        scene.fogEndDistance = 105
        scene.fogColor = sky

        let camera = SCNCamera()
        camera.fieldOfView = 70
        camera.zFar = 150
        cameraNode.camera = camera
        cameraNode.eulerAngles.x = -0.22
        scene.rootNode.addChildNode(cameraNode)

        let ambient = SCNNode(); ambient.light = SCNLight(); ambient.light!.type = .ambient
        ambient.light!.intensity = 500
        scene.rootNode.addChildNode(ambient)
        let sun = SCNNode(); sun.light = SCNLight(); sun.light!.type = .directional
        sun.light!.intensity = 900
        sun.eulerAngles = SCNVector3(-0.9, 0.4, 0)
        scene.rootNode.addChildNode(sun)

        // Runner: original character (orange body, skin head, blue cap). Feet at node origin.
        let body = SCNNode(geometry: SCNCapsule(capRadius: 0.38, height: 1.2))
        body.geometry!.firstMaterial = material(0xF97316)
        body.position = SCNVector3(0, 0.6, 0)
        let head = SCNNode(geometry: SCNSphere(radius: 0.3))
        head.geometry!.firstMaterial = material(0xFDE68A)
        head.position = SCNVector3(0, 1.45, 0)
        let cap = box(0.62, 0.14, 0.75, 0x2563EB)
        cap.position = SCNVector3(0, 1.68, -0.08)
        [body, head, cap].forEach(runnerNode.addChildNode)
        scene.rootNode.addChildNode(runnerNode)
    }

    /// One 18 m piece of track: ground, rails, sleepers and side walls.
    private func makeSegment(_ k: Int) -> SCNNode {
        let len = GameController.segmentLength
        let node = SCNNode()
        let ground = box(9, 0.2, len, 0x64748B)
        ground.position = SCNVector3(0, -0.1, -len / 2)
        node.addChildNode(ground)
        for lane in 0..<3 {
            let x = Track.laneX(lane)
            for side in [-0.75, 0.75] {
                let rail = box(0.12, 0.12, len, 0xCBD5E1)
                rail.position = SCNVector3(x + side, 0.06, -len / 2)
                node.addChildNode(rail)
            }
            var z = 0.75
            while z < len {
                let tie = box(2.0, 0.06, 0.35, 0x78350F)
                tie.position = SCNVector3(x, 0.01, -z)
                node.addChildNode(tie)
                z += 1.5
            }
        }
        let wallColor: UInt32 = k % 2 == 0 ? 0xFDBA74 : 0xA5B4FC
        for side in [-1.0, 1.0] {
            let wall = box(1, 4, len, wallColor)
            wall.position = SCNVector3(side * 5.5, 2, -len / 2)
            node.addChildNode(wall)
        }
        let flat = node.flattenedClone()
        flat.position = SCNVector3(0, 0, -Double(k) * len)
        return flat
    }

    private func makeObstacle(_ o: Obstacle) -> SCNNode {
        let x = Track.laneX(o.lane)
        let node: SCNNode
        switch o.kind {
        case .hurdle:
            node = box(2.0, 1.0, 0.5, 0xEF4444)
            let stripe = box(2.02, 0.25, 0.52, 0xFFFFFF)
            node.addChildNode(stripe)
            node.position = SCNVector3(x, 0.5, -(o.z + 0.25))
        case .bar:
            node = SCNNode()
            let bar = box(2.0, 1.0, 0.5, 0xFACC15)
            bar.position = SCNVector3(0, 1.7, 0)
            node.addChildNode(bar)
            for side in [-1.1, 1.1] {
                let post = box(0.15, 1.2, 0.15, 0x334155)
                post.position = SCNVector3(side, 0.6, 0)
                node.addChildNode(post)
            }
            node.position = SCNVector3(x, 0, -(o.z + 0.25))
        case .train:
            node = box(2.2, 3.5, Track.trainLength, 0x2563EB)
            let window = box(1.6, 1.0, 0.05, 0xBAE6FD)
            window.position = SCNVector3(0, 0.7, Track.trainLength / 2 + 0.03)   // front face (toward the runner)
            node.addChildNode(window)
            let stripe = box(2.22, 0.3, Track.trainLength + 0.02, 0xFFFFFF)
            stripe.position = SCNVector3(0, -0.6, 0)
            node.addChildNode(stripe)
            node.position = SCNVector3(x, 1.75, -(o.z + Track.trainLength / 2))
        }
        return node
    }

    private func makeCoin(_ c: Coin) -> SCNNode {
        let g = SCNCylinder(radius: 0.35, height: 0.08)
        let m = material(0xFACC15)
        m.emission.contents = UIColor(red: 0.4, green: 0.3, blue: 0, alpha: 1)
        g.firstMaterial = m
        let spin = SCNNode(geometry: g)
        spin.eulerAngles.x = .pi / 2
        let node = SCNNode()
        node.addChildNode(spin)
        node.position = SCNVector3(Track.laneX(c.lane), Track.coinY, -c.z)
        node.eulerAngles.y = Float(c.id % 8) * 0.4      // stagger the spin so coins don't all turn edge-on together
        node.runAction(.repeatForever(.rotateBy(x: 0, y: .pi * 2, z: 0, duration: 1)))
        return node
    }

    /// Makes scene nodes match `session`: adds new things, removes passed or collected ones.
    private func syncNodes() {
        let s = session.state, track = session.track
        let len = GameController.segmentLength
        let firstSeg = max(-1, Int((s.z - 10) / len) - 1)
        let lastSeg = Int((s.z + GameController.viewAhead) / len)
        for k in firstSeg...lastSeg where segmentNodes[k] == nil {
            let n = makeSegment(k); segmentNodes[k] = n; scene.rootNode.addChildNode(n)
        }
        for (k, n) in segmentNodes where k < firstSeg { n.removeFromParentNode(); segmentNodes[k] = nil }

        var live = Set<Int>()
        for o in track.obstacles where o.z < s.z + GameController.viewAhead {
            live.insert(o.id)
            if obstacleNodes[o.id] == nil { let n = makeObstacle(o); obstacleNodes[o.id] = n; scene.rootNode.addChildNode(n) }
        }
        for (id, n) in obstacleNodes where !live.contains(id) { n.removeFromParentNode(); obstacleNodes[id] = nil }

        live.removeAll()
        for c in track.coins where c.z < s.z + GameController.viewAhead && !s.collected.contains(c.id) {
            live.insert(c.id)
            if coinNodes[c.id] == nil { let n = makeCoin(c); coinNodes[c.id] = n; scene.rootNode.addChildNode(n) }
        }
        for (id, n) in coinNodes where !live.contains(id) { n.removeFromParentNode(); coinNodes[id] = nil }

        runnerNode.position = SCNVector3(s.x, s.y, -s.z)
        runnerNode.scale = SCNVector3(1, s.isSliding ? 0.5 : 1, 1)
        runnerNode.eulerAngles.x = s.crashed ? -1.2 : 0
        cameraNode.position = SCNVector3(s.x * 0.6, 4.2, -s.z + 7.5)
    }
}
```

### Task 10: Public App Store release (HUMAN steps; the agent only prints this list)

The agent **can't** sign in to Apple accounts, pay or accept agreements.

1. **Apple Developer Program:** the same membership as Jump Cube works. Agreements: App Store Connect → Business, where the Free Apps agreement must be active.
2. **Put the privacy and support pages online.** Create a public GitHub repo, for example `subwayrunner-site`, push `docs/site/` to it and turn on Settings → Pages. Put the two URLs into `store/metadata.md`.
3. **Set signing:** copy your Team ID (developer.apple.com → Membership) into `project.yml` → `DEVELOPMENT_TEAM`, then run `xcodegen generate`.
4. **Create the app record:** App Store Connect → Apps → "+" → New App → iOS, name from the metadata file, bundle ID `com.cagdasatici.subwayrunner`, SKU `subwayrunner1`. If the name is taken, use a fallback name.
5. **Upload the build:** open `SubwayRunner.xcodeproj` in Xcode, choose "Any iOS Device (arm64)", then Product → Archive → Distribute App → **App Store Connect** → Upload. For every later upload, raise `CURRENT_PROJECT_VERSION` in `project.yml` first.
6. **Fill in the listing** from `store/metadata.md`:
   - upload the screenshots (the iPhone 6.9" and iPad 13" sections)
   - answer the age-rating questionnaire
   - App Privacy → "Data Not Collected"
   - price Free
7. **Test it yourself first:** in the TestFlight tab, install the build on your son's device and play a few runs, with the sound on and with the silent switch on.
8. **Submit:** go to the version page → select the build → Add for Review → Submit. Review usually takes 1–3 days.

**If Apple rejects it:**
- **4.1** (copycat): the name or look is too close to an existing game. Switch to a fallback name, and change the colours if they ask.
- **4.3** (spam): too much like other runner apps.
- **4.2** (minimum functionality): the app is too thin.

For 4.3 or 4.2, add one post-MVP feature (such as a character colour picker or a magnet power-up), raise the build number and resubmit.
